# FlarpyBarb

A 2D arcade game built with Unity. Guide a bird through the pipes, earn points, and try to beat your score.

## Features

- Cyan bird and twilight colors
- Random pipe obstacles and score counter
- Flap, score, and crash sound effects
- Looping background music
- Game-over screen with a restart button
- Author watermark

## Getting started

1. Clone or download this repository.
2. Open the project in Unity Hub with **Unity 6000.3.27f2**.
3. Wait for Unity to import the assets and compile the scripts.
4. Open `Assets/Scenes/GameScreen.unity`.
5. Press **Play**.

## Controls

Press **Space**, click, or tap to flap. Pass between the pipes to score. Hitting a pipe or flying outside the screen ends the round. Select **Fly Again** to restart.

## Project structure

- `Assets/Scenes` - Game scene
- `Assets/Scripts` - Gameplay and audio scripts
- `Assets/Prefabs` - Pipe prefab
- `Assets/Sprites` - Game artwork
- `Assets/Resources/Audio` - Sound effects and music
- `Packages` - Unity package dependencies
- `ProjectSettings` - Unity project configuration
